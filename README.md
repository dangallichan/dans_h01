# dans_h01

Files helping me explore the amazing H01 dataset: [https://h01-release.storage.googleapis.com/gallery.html](https://h01-release.storage.googleapis.com/gallery.html)

---


Create a new issue using the template and it will update that line only of the JSONL file

Use this page to generate the line: [https://dangallichan.github.io/dans_h01/filter_json_url.html](https://dangallichan.github.io/dans_h01/filter_json_url.html)

And view the data here: [https://dangallichan.github.io/dans_h01/viewData.html](https://dangallichan.github.io/dans_h01/viewData.html)

General converter: [https://dangallichan.github.io/dans_h01/convert_json_url.html](https://dangallichan.github.io/dans_h01/convert_json_url.html)

And the other way, JSON to URL: [https://dangallichan.github.io/dans_h01/convert_json_to_url.html](https://dangallichan.github.io/dans_h01/convert_json_to_url.html)
